# 场景 7 · 分层词库（做上架）

**何时用**：把反查+拓展的词池按角色分工，输出五张清单（标题/五点/后台/广告/否定）。

**提示词**（【】内替换为实际值；【数据MCP】= 环境中已接入的数据源 MCP）：

```
基于【核心词+竞品 ASIN 列表】帮我搭建新品关键词库。词不要按搜索量排队交给我，要按角色分工组织：
① 拉全词池：反查+流量词拓展，每个词给搜索量、购买率、竞争度、相关度
② 角色分类：每个词先判性——共性词/属性词/品牌词/品类词/受众词/场景词，品牌词里区分自家（主攻）和竞品（可截流）
③ 分工输出五张清单：标题位（搜索+相关性双高的核心词，≤5 个）、五点位（场景词+长尾，每点配 1~2 个）、后台位（正文放不下但不舍得丢的长尾）、广告位（购买率优先）、否定位（看着相关但抢了也不转化的）
④ 成本标注：广告位的词标 SPR 和 PPC 竞价区间——进去之前知道要花多少
数据标注来源和统计周期。最后给使用建议：标题埋词的取舍逻辑、首月广告先开广告位里的哪几个词、为什么。输出为五张分工清单+词池总表。
```
