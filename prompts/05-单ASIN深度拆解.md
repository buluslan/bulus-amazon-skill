# 场景 5 · 单 ASIN 深度拆解（定打法）

**何时用**：对锁定的腰部对标做深度拆解，还原它的决策逻辑（文案/变体/价格/评论信号）。

**提示词**（【】内替换为实际值；【数据MCP】= 环境中已接入的数据源 MCP）：

```
帮我深度拆解美国站这个竞品：【ASIN】。重点不是罗列它的数据，是还原它的决策逻辑：
① 现状盘点：价格、评分、评论数、类目排名、变体数、LQS（Listing 质量分）、认证标识
② 文案决策：标题的关键词排序逻辑（核心词、属性词、场景词怎么排兵布阵），五点每条在打什么心理（痛点回应/差异证明/信任背书），埋词密度对比
③ 结构决策：变体矩阵怎么设计的（几个尺寸/颜色/组合装，哪个是引流款哪个是利润款），用销量数据验证哪个变体在扛量
④ 价格决策：用 Keepa 价格历史还原它过去 12 个月的价格和促销动作——什么时候降价、降多少、降完销量什么反应
⑤ 趋势：近 90 天销量和 BSR 走势，判断它在上升、稳态还是衰退
⑥ 评论信号：拉它的差评归类——被反复骂的 Top 2（这是我的可攻击点）、被夸但 Listing 没宣传的（隐藏卖点，我直接拿来的差异化素材）、买家高频使用场景（我图片规划的素材）
数据标注来源和统计周期。最后回答两个问题：它为什么卖得好（给 3 个以内的核心原因，按重要性排序）；它有什么可攻击的短板（给 1~2 个，附数据依据）。输出为竞品决策拆解报表。
```
