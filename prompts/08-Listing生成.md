# 场景 8 · Listing 生成（做上架）

**何时用**：吃掉前序全部数据，生成 75 字符合规的完整 Listing+埋词对照表。

**提示词**（【】内替换为实际值；【数据MCP】= 环境中已接入的数据源 MCP）：

```
基于上面几步产出的【市场体检/竞品拆解/分层词库】数据，为我的产品写一条完整的亚马逊 Listing。

我的产品：产品名【】、核心参数【材质/尺寸/适用场景】、差异化卖点【2~3 条】

要求：
1. 标题 ≤75 字符（2026-07-27 新规硬线），标题位主攻词埋进前半段
2. 商品亮点 ≤125 字符，至少 3 个短语
3. 五点每条只讲一个卖点：前两条打竞品拆解里发现的空位，后三条覆盖场景和信任；每条埋 1~2 个五点位关键词
4. 后台搜索词：只放后台位清单里的词，不与正文重复、不含品牌词
5. 否定位的词一个都不许出现
6. 硬参数（材质/尺寸/数量）只用我提供的，不许编

先输出完整 Listing（标题/亮点/五点/后台搜索词），再输出一张埋词对照表：每个埋词位置标来源词、它在词库里的角色、搜索量和购买率——让我能核对文案是不是真的吃了数据。输出为可直接上架的文案+对照报表。
```
