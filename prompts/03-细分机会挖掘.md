# 场景 3 · 细分机会挖掘（看市场）

**何时用**：趋势确认有增量后，从大类目里挖"新品真能拿到订单"的细分切入点。

**提示词**（【】内替换为实际值；【数据MCP】= 环境中已接入的数据源 MCP）：

```
我在美国站【大类目】里找细分切入点。请用【数据MCP】 扫描机会，不要只按搜索量从高到低排，我要的是"新品真能拿到订单"的方向：
① 扫描该类目相关关键词，每个词给：月搜索量、购买率、点击集中度（头部是否锁死点击）、商品数、供需比
② 区分两类假机会：搜索量高但点击被头部锁死的词；用户会广泛点击但订单仍集中在头部的词——这两类单独列出，标"仅曝光机会，无订单机会"
③ 给真机会词补充竞争成本：SPR（推上首页所需销量）、广告竞品数、标题密度、PPC 竞价区间——判断进去要花多少钱
④ 标注信号词：近 3 个月增长率超过 20% 的新兴词、带 Amazon's Choice 的词
数据标注来源和统计周期。最后把所有词分四档：优先研究 / 可切入但需验证 / 有门槛再评估 / 暂不投入；选出最值得深挖的 3 个词，每个说明数据依据。输出为机会词分档报表。
```
